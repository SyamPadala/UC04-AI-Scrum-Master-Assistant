## 3. Intent matching (#9) — what changed and why

Causes found: a code guard kept a match only if the member's words shared a
word with the story **title**; the model saw titles only; her own stories were
listed first; the smallest model was used.

- **Story descriptions sent:** User Story + Acceptance Criteria from the Jira
  description (≤800 characters per story, "Design Traceability" dropped) —
  `src/pm/about.ts`, `src/pm/jira.ts` (SPEC-004 item 32).
- **Keyword guard removed:** the model gives a `reason` per match; code rejects
  only missing or vague reasons (`requireReason`, `reasonIsSpecific` in
  `src/agents/updateProcessor.ts`) (item 33).
- **Stories listed in key order**, owner shown as plain information (item 32).
- **Matching rules (user decisions, items 34 and 38):**
  - Her own story fits → recorded straight away, nothing else checked.
  - Otherwise → **one card** (`src/cards/storyChoice.ts`): her own open stories
    first, then every other story it could fit, max 5, **Submit per row** (no
    second confirmation), **None of these**.
  - Blockers use the same card: Submit writes the Blocked row then alerts the
    Scrum Master with that story; None of these writes nothing but still alerts
    (no story, her open items listed).
  - A blocker that fits no story at all ("my laptop is broken") → alerted at once.
- **Model:** Agent 1 runs on **`gemini-3.5-flash` everywhere** — dev, eval and
  production (user: "we are going to use flash from now"). Default set in
  `src/config/env.ts` (`AGENT1_MODEL`). Agent 2 (summary) stays on `LLM_MODEL`
  (flash-lite). Answer limit 8,192 tokens (flash's thinking counts against it;
  at 1,024 it cut answers off on 20 of 69 cases).
- **Eval:** 69 cases (10 new must-pass: intent, run-on, own-first);
  `eval/stories.json` now has descriptions. Last full run **on flash: 94.2%,
  must-pass 9/10** (e63: right story and alternatives, status Completed instead
  of In Progress). Flash-lite run: 92.8%, 9/10. The item-38 prompt change
  ("list every plausible story") was **not** re-evaluated; tested live instead.
